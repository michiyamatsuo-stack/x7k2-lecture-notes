# ジャーナリズム実習 学生作品アーカイブ

学生が制作した記事作品・動画作品を一覧・公開するための静的サイトです。
フレームワーク不要、プレーンなHTML/CSS/JSで構成されており、GitHub Pagesでの公開を想定しています。

- 前期「ジャーナリズム実習基礎」＝ 個人作品（1作品＝1著者）
- **後期「ジャーナリズム実習」＝ 班単位の共同制作（1作品＝1班）**

2026年9月4日に、後期の班単位の記事に対応したテンプレートへ更新しました。

## フォルダ構成

```
my-lecture-site/
├── index.html                  トップページ（作品一覧）
├── robots.txt                  検索エンジン向け設定（noindex運用のためクロールは許可）
├── data/
│   └── works.json              作品一覧データ（一覧表示はここを見て自動生成される）
├── works/
│   ├── template-article.html   記事作品ページの雛形（班単位）
│   ├── template-video.html     動画作品ページの雛形（班単位）
│   ├── sample-group.html       ★記入例（完成形の見本）
│   └── work01.html などの実ページ
├── images/                     写真・グラフィックの画像ファイル
├── css/style.css               全ページ共通スタイル
└── js/main.js                  トップページの一覧描画ロジック
```

## 後期（班単位）の記事ページの構成

1ページが「ウェブのニュース記事1本」です。上から下へ、次の順に並びます。

| 順 | 要素 | HTMLのクラス | 分量 |
|---|---|---|---|
| 1 | 著者欄（**班名**＋班員全員） | `.work-profile` | ― |
| 2 | 見出し／サブ見出し | `.work-title` / `.work-subtitle` | 25〜35字 |
| 3 | メイン写真＋キャプション | `figure.inline-photo` | ― |
| 4 | リード | `.work-lead` | 100〜150字 |
| 5 | 本記（小見出し＋本文＋署名） | `h2` / `p` / `.part-credit` | 600〜800字 |
| 6 | 写真2 | `figure.inline-photo` | ― |
| 7 | 雑観（小見出し＋本文＋署名） | `h2` / `p` / `.part-credit` | 300〜400字 |
| 8 | グラフィック | `figure.inline-graphic` | 1点以上 |
| 9 | 解説／用語解説 | `h2` / `p` / `.part-credit` | 200〜300字 |
| 10 | 談話（任意） | `aside.work-danwa` | 150〜250字 |
| 11 | クレジット（班員全員） | `.work-credit` | ― |
| 12 | 取材源・参考資料 | `details.work-sources` | ― |

**完成形は `works/sample-group.html` を見てください。**（トップページにも【記入例】として並んでいます）

### 著者欄は「班名」

共同制作なので、著者欄には個人名ではなく**班名**を入れます。
班員全員の名前は、`.work-profile__members` と、記事末の `.work-credit` の2カ所に出ます。

### 署名の入れかた

| 誰 | どこに | 書き方 |
|---|---|---|
| 原稿を書いた人 | その原稿の直後 | `<p class="part-credit">（文・○○○○）</p>` |
| 写真を撮った人 | キャプションの末尾 | `…＝2026年11月5日、○○、○○○○撮影` |
| 図表を作った人 | 図表の出典行の末尾 | `（グラフィック・○○○○）` |
| 班全員 | 記事の最後 | `.work-credit` の各行 |

学年・学籍番号は出しません。氏名のみです。

### 写真のキャプション書式

```
何が写っているか ＝ 撮影年月日、撮影場所、撮影者名撮影
```

### グラフィックの3点セット

`figure.inline-graphic` の `figcaption` には、次の3つを必ず入れます。

- **タイトル**（何を示す図か）… `<span class="graphic-title">`
- **出典**（どこの数字か・いつの数字か）… `<span class="graphic-source">`
- **単位・母数**（何人中／単位）… 同じく `graphic-source` に続けて書く

## 新しい作品を追加する手順

1. **ページを複製する**
   - 記事作品: `works/template-article.html` をコピーし、`works/work05.html` のような名前で保存
   - 動画作品: `works/template-video.html` を同様にコピー

2. **複製したページの中身を差し替える**
   - `<title>` を記事の見出しに変更
   - `【　】` で囲まれた箇所をすべて実際の内容に差し替える（差し替え漏れがないか、ページ内を「【」で検索して確認）
   - 使わないパート（談話・サブ見出しなど）は、コメントに従ってブロックごと削除
   - 写真・グラフィックの画像は `images/` に置き、`src="../images/ファイル名"` で参照

3. **`data/works.json` に1件分の情報を追加する**
   ```json
   {
     "id": "work05",
     "title": "記事の見出し",
     "student": "班名",
     "thumbnail": "images/サムネール画像.jpg",
     "type": "article",
     "page": "works/work05.html"
   }
   ```
   - `student` は**班名**を入れます（一覧カードに表示されます）
   - `type` は記事なら `"article"`、動画なら `"video"`
   - 配列の要素はカンマ区切り。**最後の要素の後ろにカンマを付けない**（JSONの記法エラーになります）

4. **ブラウザで確認する**
   - 下記「ローカルでの確認方法」でサーバーを起動し、カードと個別ページを確認

## 作品を削除する場合

`data/works.json` から該当する項目を削除するだけでOKです（HTMLファイル自体は残しても消しても構いません）。

## トップページの説明文を変更したい場合

`index.html` 内の `<p class="site-description" id="site-description">` のテキストを直接書き換えてください。

## スタイルを変更したとき

`css/style.css` を編集したら、ブラウザのキャッシュ対策として全HTMLの
`style.css?v=3` の数字を1つ増やしてください（`?v=4` など）。

## ローカルでの確認方法

`data/works.json` を `fetch` で読み込む都合上、`index.html` をダブルクリックして直接開くと
ブラウザのセキュリティ制限で一覧が表示されません。ローカルサーバーを立てて確認してください。

```bash
# フォルダ内で実行
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pages での公開

```bash
git add .
git commit -m "作品を追加"
git push
```

反映まで1〜2分かかることがあります。公開URLは
<https://michiyamatsuo-stack.github.io/x7k2-lecture-notes/> です。

全ページに `noindex` を入れてあるため検索エンジンには出ませんが、
URLを知っていれば誰でも見られる状態です（本当のアクセス制限ではありません）。
